# 更新日志 / Changelog

## [0.1.0] - 2026-08-25

Initial release: a multi-version / multi-instance DSH launcher built with Tauri 2 + Vue 3.

- Multi-version installs (isolated pnpm dirs), multi-instance management, three DSH_HOME modes, environment overrides.
- System tray (double-click opens the last focused profile, "Running profiles" submenu), close-to-tray, launch at login.
- News source setting on the Settings page (md with GFM + inline HTML, XSS-sanitized before display).
- Simplified Chinese / English UI.
